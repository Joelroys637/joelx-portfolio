# Factorial program
செயல் காரணியம்(n)
    என்றால் n <= 1

WHY TAMILSCRIPT

Built for thinking in Tamil, not translating into it

Most languages force you to think in English syntax before you can express an idea. TamilScript removes that translation step entirely.

🅃

100% Tamil keywords

Every control word — என்றால், வரை, செயல் — is native Tamil. No mixed-language syntax to memorise.

🌱

Made for beginners

A small, predictable keyword set and one consistent closing word — முடிவு — for every block.

🗂️

Ordered, example-first docs

Each chapter pairs an explanation with a runnable snippet and its expected output, in the order you'll actually need them.

🔁

Familiar building blocks

Variables, loops, conditionals and functions — the same concepts you'd learn in any language, expressed in Tamil.

🧮

Full operator set

Mathematical, relational and logical operators, documented side-by-side with their Tamil names.

🆓

Free & open reference

No sign-up, no paywall — every chapter is open to read, copy and reuse.
